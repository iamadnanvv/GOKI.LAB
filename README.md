# Sticker Rebellion

Design a premium, mobile-first e-commerce website for an independent satirical sticker brand inspired by the viral "Main Bhi Cockroach" movement. The website should clearly communicate that the products are original artistic creations for creative civic expression and are NOT official merchandise, are not affiliated with any political party, organization, or movement, and are independently designed.

- Bold

- Youth-driven

- Rebellious

## Visual Style

Create a clean, modern interface with generous whitespace and bold typography.

Color Palette

- Matte Black (#111111)

- Off White (#F8F8F8)

- Neon Green (#7CFF4F)

- Signal Red (#FF3B30)

- Electric Yellow (#FFD60A)

- Soft Gray (#E8E8E8)

Typography

- Large bold headings

- Modern sans-serif font

- High contrast

- Editorial-inspired layouts

- Dynamic oversized text

Use subtle grain textures, sticker-cut outlines, graffiti-inspired accents, and layered paper effects without making the interface feel cluttered.
